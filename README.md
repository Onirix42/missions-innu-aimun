# Missions innu-aimun

Jeu web pour apprendre du vocabulaire en **innu-aimun**, langue seconde, destiné aux jeunes de 8 à 15 ans. Les sons proviennent du dialecte de **Uashat mak Mani-utenam**.

**Jouer en ligne : [onirix42.github.io/missions-innu-aimun](https://onirix42.github.io/missions-innu-aimun/)**

## Activités

- **🔎 Explorer** : toucher les repères ou les mots pour les découvrir et les écouter.
- **🎯 Trouver le repère** : le jeu donne un mot innu; on touche le bon endroit sur l’illustration.
- **🧩 Choisir le mot** : un repère est en orange; on choisit le mot innu correspondant.
- **🗂️ Animé ou inanimé ?** : on range chaque nom dans la bonne catégorie grammaticale.

Une aide en français peut être affichée ou cachée, et chaque mot enregistré peut être écouté à vitesse normale ou ralentie.

## Thématiques

Le corps (Uiau), les couleurs (Atishauiana), les chiffres (Atshitashuna), les animaux (Aueshishat), les poissons (Nameshat), le calendrier (Tshishtekaikan), les pronoms, et animé ou inanimé. Au total, 189 mots, dont 144 avec un enregistrement.

On peut ouvrir directement une thématique avec l’adresse `index.html#corps`, `#couleurs`, `#chiffres`, `#animaux`, `#poissons`, `#calendrier`, `#pronoms` ou `#genre`.

## Utilisation

L’application tient dans un seul fichier `index.html`, accompagné du dossier `img/`. Il n’y a rien à installer : on ouvre `index.html` dans un navigateur, ou on publie le dépôt avec GitHub Pages. Une connexion Internet est nécessaire pour les sons, qui sont lus depuis leurs sites d’origine. Aucun compte, aucun classement : la progression s’efface à la fermeture de la page.

## Sources

- [Leçons d’innu (innu-aimun.ca)](https://lessons.innu.atlas-ling.ca/) : enregistrements du dialecte central (Uashat mak Mani-utenam), genre des noms.
- [Atlas linguistique algonquien](https://www.atlas-ling.ca/) : phrases enregistrées par Doris Vollant (Uashat mak Mani-utenam) pour les pronoms.
- [Grammaire d’innu-aimun.ca](https://www.innu-aimun.ca/francais/grammaire/) : pronoms personnels, genre et pluriel des noms.
- Fiches papier de vocabulaire fournies par l’auteur.

Les enregistrements appartiennent à leurs auteurs et ne sont pas copiés dans ce dépôt. Les illustrations des animaux et des poissons ont été générées par IA.

## Avertissement

Les formes, traductions et explications sont une transcription de travail. Elles doivent être validées par des locutrices et locuteurs innus avant une diffusion en classe.
